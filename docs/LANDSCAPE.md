# 手机横屏布局

手机横过来以后，宽度约 780 – 900dp，高度只剩 340 – 400dp（扣掉状态栏与手势条约 345dp）。竖屏的"大标题 + 卡片纵向堆叠"在这个比例下一屏只能放下一张卡，用户要不停上下滑。横屏布局的原则是：**把高度留给内容，把宽度拆成两栏**。

## 一、总原则

| 原则 | 做法 |
| --- | --- |
| 高度是稀缺资源 | 页头压成一行（标题 + 动作），去掉眉题与副标题；底部不放悬浮按钮，主要动作进左栏 |
| 两栏分工 | 左栏（约 2/5）放"控制与概况"：筛选、状态、按钮、统计；右栏（约 3/5）放"长内容"：列表、原文、实时转写，独占整屏高度、独立滚动 |
| 左侧导航栏 | 600dp 起已改为侧栏导航，横屏沿用；四个标签竖排正好放进 345dp |
| 筛选片换行 | 竖屏里横向滚动的筛选片，横屏在左栏换行平铺，所有选项一眼可见 |
| 列表单列 | 右栏宽约 460dp，卡片单列；只有 1200dp 以上的横持平板才用两三列 |
| 底部面板 | 新建待办、粘贴文字沿用完全展开的底部面板；键盘弹出时面板自身滚动 |
| 手势不变 | 右滑完成、左滑推迟、长按多选、下拉刷新在横屏一致 |

## 二、各页面

| 页面 | 左栏 | 右栏 | 横屏比竖屏多看到什么 |
| --- | --- | --- | --- |
| 概览 | 日期一行；待推进件数与「开始录音 / 导入录音」；自动转写状态（进度、计数、正在转写的文件与实时文字、暂停 / 查看过程） | 三步设置（未完成时）；今日必办；最近录音；快捷操作 2×2 | 转写进度和最近录音同屏，不用滑动 |
| 录音库 | 标题与份数；搜索框；五个状态筛选片换行平铺；「导入录音」 | 录音卡片单列，整屏高度 | 筛选与搜索常驻，列表可见行数从 2 张卡增加到 3 – 4 张 |
| 待办 | 标题与「多选」；五个时段筛选片换行；筛选说明；「新建待办」 | 时段总结卡、分类 / 状态筛选、待办卡片；多选工具栏贴在右栏底部 | 时段切换与列表同屏 |
| 录音详情 | 标题、状态片、播放器、「纪要 / 待办 / 润色」切换与对应内容 | **原文常驻**：按说话人着色的转写全文，独立滚动 | 看纪要或核对待办时原文一直在旁边，这是横屏最大的收益 |
| 转写过程 | 当前文件、引擎、进度、片段与说话人统计；「选一个录音试转」「允许后台运行」 | 逐段文字流，整屏高度，仍只在停在底部时跟随新内容 | 状态不再挤占文字区 |
| 现场录音 | 计时器（缩小到 40sp）、电平、开始 / 停止、说明 | 实时文字与历史录音，整屏高度 | 录音时能看到更多实时文字 |
| 首次向导 | 步骤号、标题、副标题；「上一步 / 下一步」固定在左栏底部 | 当前步骤的内容（模型卡、目录列表、范围选择、处理进度） | 按钮不再被长内容顶出屏幕 |
| 我的 / 设置 / AI 整理方式 / 声纹库 | 保持竖屏结构，内容列居中限宽 | — | 列表型页面横屏无需拆栏 |

两栏宽度比固定 2 : 3；内容整体限宽 1440dp，在横持平板上居中。

## 三、适用范围与优先级

- 横屏变体放在 `layout-land/`，对所有横屏窗口生效：手机横屏、折叠屏展开横持、平板横持。
- 概览与我的在 1200dp 以上有 `layout-w1200dp/` 的双栏仪表盘，录音库与待办在 1200dp 以上保留三列网格；Android 按"可用宽度"优先于"方向"选择资源，所以横持平板仍走宽屏布局，横屏变体只落到手机和中等宽度的折叠屏。
- 录音详情、转写过程、现场录音、向导的两栏在平板横屏上同样适用，不另做宽屏版本。

## 四、实现

| 机制 | 位置 |
| --- | --- |
| 横屏布局 | `res/layout-land/`：`fragment_home`、`fragment_library`、`fragment_todos`、`activity_recording_detail`、`activity_live`、`activity_microphone`、`activity_onboarding`，视图 id 与竖屏版一致 |
| 平板横屏保护 | `res/layout-w1200dp/fragment_library.xml`、`fragment_todos.xml` 与竖屏版相同，保证 1200dp 以上仍是网格 |
| 两栏标记 | 横屏布局的左栏带 `@id/sidePane`，页面代码据此改为单列并放宽到 1440dp；两栏容器带 `@id/panes`，系统栏内边距加在整行上 |
| 详情页原文栏 | `@id/tvTranscript` 存在时隐藏「原文」切换按钮，原文直接渲染到右栏 |
| 现场录音 | 横屏时左右并排，不再做半开桌面姿态的上下拆分 |

## 五、验证

真机横过来即可；没有真机时在任意设备上模拟手机横屏：

```sh
adb shell wm size 1280x2772 && adb shell wm density 520   # 394 x 853 dp
adb shell settings put system user_rotation 1
# 恢复
adb shell wm size reset && adb shell wm density reset
```

检查项：侧栏四个标签可见；概览左栏能看到转写进度、右栏能看到最近录音；录音库筛选片全部可见且列表至少 3 张卡；待办多选工具栏在右栏底部；详情页左侧切换纪要 / 待办时右侧原文不动；转写过程文字区高度不小于屏幕的 80%；向导「下一步」始终可见；旋转回竖屏后筛选与步骤保持。
