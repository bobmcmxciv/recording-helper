# 折叠屏与大屏适配

录音助手按**窗口尺寸**而不是机型来决定布局。同一套界面覆盖直板手机、小折叠（Flip 类）的外屏与内屏、大折叠（Fold / Find N / Mate X / MIX Fold / Magic V）的内屏、三折与阔折叠（Mate XT 类）全展开，以及平板与桌面窗口。

## 窗口宽度三档

| 档位 | 窗口宽度 | 典型设备 | 导航 | 内容列 | 列表 |
| --- | --- | --- | --- | --- | --- |
| 紧凑 Compact | < 600dp | 直板手机、小折叠外屏与内屏、大折叠外屏 | 底部导航栏 | 全宽 | 单列 |
| 中等 Medium | 600 – 839dp | Mate X5 内屏（约 800dp）、分屏中的大折叠、竖持平板 | 左侧导航栏（Navigation Rail） | 居中，最宽 720dp（向导 640dp） | 单列 |
| 扩展 Expanded | ≥ 840dp | Galaxy Z Fold 内屏（约 920dp）、Find N3（约 840dp）、三折全展开（1000dp 以上）、横持平板 | 左侧导航栏 | 居中，最宽 1080dp | 录音库与待办两列网格 |

宽度来自 `Configuration.screenWidthDp`，折叠、展开、旋转、分屏都会重新计算，页面随之重建。

## 各页面规则

| 页面 | 紧凑 | 中等 | 扩展 |
| --- | --- | --- | --- |
| 概览 | 单列卡片 | 居中 720dp | 居中 720dp |
| 录音库 | 单列 | 居中 720dp | 两列卡片网格，搜索与筛选横跨全宽 |
| 待办 | 单列 | 居中 720dp | 时段总结卡、筛选条与分组标题横跨两列，待办卡片两列；滑动与多选不变 |
| 我的 | 单列 | 居中 720dp | 居中 720dp |
| 首次向导 | 全宽 | 内容与底部按钮居中 640dp | 同中等 |
| 录音详情 / 设置 / AI 整理方式 / 声纹库 | 全宽 | 居中 720dp | 居中 720dp |
| 现场录音 | 控制面板固定在上方，实时文字在下方滚动 | 同紧凑，居中 720dp | 同中等 |
| 转写过程 | 全宽滚动 | 居中 720dp | 居中 720dp |
| 底部面板（新建待办、粘贴文字、导入方式） | 全宽 | Material 3 模态面板默认限宽 640dp 居中 | 同中等 |

设计原则：

- 行长不超过约 40 个汉字，所以阅读型页面限宽而不是铺满。
- 两列网格只用于卡片型列表；每张卡片在半宽（约 500dp）下仍完整显示标题、分类、期限和依据。
- 大屏下不新增功能，只调整排布；所有手势（滑动完成 / 推迟、长按多选、下拉刷新）在任何档位一致。

## 折叠姿态与铰链

通过 Jetpack WindowManager 的 `FoldingFeature` 读取姿态；没有铰链的设备收不到任何事件，布局不变。

| 姿态 | 判定 | 处理 |
| --- | --- | --- |
| 平展 | `FLAT` 或无铰链 | 按宽度档位排布 |
| 桌面模式（横向铰链，半开放置） | `HALF_OPENED` + `HORIZONTAL` | 现场录音：实时文字占铰链上方，计时器、电平与开始 / 停止按钮放到铰链下方，面板上边留出铰链高度；其他页面不变 |
| 书本模式（纵向铰链，半开手持） | `HALF_OPENED` + `VERTICAL` | 视为扩展宽度，两列网格天然以铰链为界，不把单张卡片横跨铰链 |

`isSeparating` 为真的铰链（物理双屏）按书本 / 桌面规则处理；屏幕中缝不是物理分隔时允许内容连续。

## 状态连续性

- 折叠或展开会触发配置变化，页面重建；录音与转写运行在前台服务里，不中断。
- 待办的时段、分类、状态筛选与多选集合，向导的当前步骤，详情页的滚动位置，重建后保持。
- 不在清单里声明 `configChanges` 自行处理尺寸变化，避免布局停留在旧档位。
- 多窗口与分屏按实际窗口宽度判断，不读取物理屏幕尺寸。

## 实现

| 机制 | 位置 |
| --- | --- |
| 导航栏切换 | `res/layout/activity_main.xml`（底部导航）与 `res/layout-w600dp/activity_main.xml`（侧栏），两者绑定为同一 `NavigationBarView` |
| 宽度档位与限宽 | `ui/Ui.kt`：`Ui.width()`、`Ui.column(view, maxDp)`；侧栏的系统栏内边距由 `Ui.railInsets()` 处理 |
| 两列网格 | `LibraryFragment`、`TodosFragment` 在扩展档位使用 `GridLayoutManager`，总结卡、筛选条、分组标题、空状态占满两列 |
| 折叠姿态 | `Ui.tabletop()` 订阅 `WindowInfoTracker`；`MicrophoneActivity.fold()` 在桌面模式交换面板顺序并对齐铰链 |
| 依赖 | `androidx.window:window:1.3.0` |

## 验证

有折叠真机时逐项检查：外屏 → 内屏切换不丢筛选与步骤；内屏两列网格；桌面模式下录音控制在铰链下方；书本模式下卡片不跨缝。

没有折叠真机时，用模拟器的 Pixel Fold、7.6" Fold-in、8" Fold-out 配置（`adb emu fold` / `adb emu unfold` 切换），或在任意真机上临时改写窗口尺寸：

```sh
# 中等宽度（约 680dp）：侧栏 + 居中列
adb shell wm size 1280x1280 && adb shell wm density 300
# 扩展宽度（约 890dp）：侧栏 + 两列网格
adb shell wm density 230
# 恢复
adb shell wm size reset && adb shell wm density reset
```

检查项：侧栏四个标签可切换且高亮正确；概览、我的、向导、详情内容居中且不贴边；待办两列时滑动完成 / 推迟与多选仍可用；录音库两列时搜索、筛选、FAB 可用；旋转与恢复尺寸后无崩溃。
