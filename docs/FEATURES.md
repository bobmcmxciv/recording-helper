# 功能清单

录音助手要解决的问题只有一个：**手机上的通话和会议录音，变成可以执行的纪要和待办，而且不离开手机。**
下面按使用链路列出系统需要的全部功能，并标注当前状态。

状态说明：✅ 已实现并在真机验证 · 🟡 已实现、覆盖面有限 · ⬜ 规划中

## 1. 录音进入系统

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 首次打开向导 | ✅ | 欢迎 → 下载 / 导入模型（推荐来源清单，SHA-256 校验，进度与速度）→ 授权录音来源（各品牌目录计数）→ 选择处理范围 → 实时处理反馈（当前文件、流式文字、进度）→ 完成；中途退出下次从断点继续 |
| 自动发现系统录音 | ✅ | 三种方式：读取音频权限（系统索引的录音文件，不需要全部文件权限）、授权录音目录（SAF）、全部文件权限；每 15 分钟扫描一次；内置小米 / Redmi、OPPO / 一加 / realme、HONOR / 华为、vivo / iQOO、三星的候选路径 |
| 处理范围由用户决定 | ✅ | 首次必须明确选择：仅新增 / 最近 N 天 / 全部 / 暂不开启；升级和重启不改变选择 |
| 持久化队列 | ✅ | 只记录引用不复制整库，每批 3 条，可暂停、继续、重试失败项 |
| 手动导入 | ✅ | 系统文件选择器多选；支持 mp3 / m4a / wav / amr / aac / ogg / opus / flac / 3gp / mp4 |
| 系统分享接收 | ✅ | 录音机或文件管理器分享到「录音助手」；分享文字也可直接导入 |
| 应用内录音 | ✅ | 前台服务 + 通知停止；16 kHz WAV 私有保存；中断可修复并补转写 |
| 粘贴文字 | ✅ | 会议记录、聊天内容走同一条本机整理管线 |

## 2. 本机处理

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 本机语音转文字 | ✅ | SenseVoice-Small（TFLite）；默认稳定 CPU，可选 NPU 加速（联发科 NeuroPilot / 高通 QNN / NNAPI） |
| 分段实时转写 | ✅ | 应用内录音约每 5 秒出一段文字；不是逐字流式 |
| 说话人区分 | ✅ | 可选 CAM++ 声纹模型；两人以上时按「名字：文字」逐行输出 |
| 本机纪要与待办 | ✅ | Qwen3.5 GGUF（llama.cpp）；每条待办必须引用原文句子作为依据，无法对应原文的待办会被拒绝；自动标注公事 / 私事 |
| 在线 AI 整理（可选） | ✅ | 用户阅读并勾选风险告知后才可启用；预置 OpenAI、Anthropic、DeepSeek、阿里云百炼、智谱、Moonshot、Gemini，以及 OpenAI 兼容 / Anthropic 兼容两种自定义接入；可设仅 Wi-Fi 发送；随时改回本地 |
| 可选润色稿 | ✅ | 原文永远保留，润色只是额外一份 |
| 充电时自动整理 | ✅ | 转写优先于 LLM；录音和声纹分析时 LLM 让出模型 |
| 长录音分段处理 | ✅ | 1200 字一段 map / reduce，不静默截断 |

## 3. 整理与查看

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 概览页 | ✅ | 待推进数量、今日必办、自动转写进度与正在转写的文件和实时文字、最近录音、三步设置引导 |
| 录音资料库 | ✅ | 搜索标题 / 原文 / 纪要，按状态筛选，列表显示待办数和说话人数 |
| 录音详情 | ✅ | 纪要 / 待办 / 原文 / 润色四个视图；原文按说话人着色；应用内录音可回放；复制、分享、重新整理、删除 |
| 待办清单 | ✅ | 按来源录音时间筛选（今天 / 本周 / 本月 / 全部 / 自定义）；公事 / 私事 / 未分类筛选与一键改分类；时段总结卡（数量统计 + AI 总结 + 建议先做的 3 件）；右滑完成、左滑推迟、长按多选批量完成 / 推迟 / 忽略 / 改分类；期限识别；编辑；跳转来源录音 |
| 删除同步 | ✅ | 删除以墓碑标记，其他设备与看板同步隐藏 |
| 导出 | ✅ | JSON 导出转写、纪要、待办和冲突副本 |
| 转写过程页 | ✅ | 当前文件、引擎、每段文字与模型耗时实时刷新；列表只在停在底部时跟随新内容，手指拖动期间和拖离底部后不再自动跳动 |
| 从导出恢复 | ⬜ | 当前只能导出，尚无导入恢复入口 |

## 4. 声纹

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 一键录入本人 | ✅ | 约 20 秒朗读，自动检查音量、削波和一致性；不合格不覆盖旧声纹 |
| 辨认当前说话人 | ✅ | 约 10 秒；只显示「疑似」，不做身份认证 |
| 录入其他人 | ✅ | 须对方本人朗读并同意 |
| 从多段双人通话发现对方声纹 | 🟡 | 以本人声纹为锚点，跨录音保守聚类，人工试听确认后命名入库；合成语音验证通过，真人通话效果待更多实测 |
| 声纹库本机隔离 | ✅ | 向量不同步、不导出、不进入备份 |

| 部署模板 | 🟡 | Docker Compose、nginx、Caddy、systemd 示例已提供，未在全部环境实测 |

## 6. 隐私与系统

| 功能 | 状态 | 说明 |
| --- | --- | --- |
| 默认离线 | ✅ | 不配置服务器也能完整使用；模型安装后推理不联网 |
| 模型自行导入或 HTTPS 下载 | ✅ | 下载强制 SHA-256 校验，`.part` 不视为已安装 |
| 息屏后台处理 | 🟡 | 请求解除电池优化；厂商自启动限制需用户在系统设置中处理 |
| 机型覆盖 | 🟡 | Redmi（HyperOS）与 OPPO Find X9 Pro（ColorOS）真机验证；HONOR / vivo 仅候选路径，未真机验证 |
| 芯片要求 | 🟡 | 预编译 LLM 库需要 arm64 + dotprod + i8mm；更老的芯片需要重新编译 native 库 |
| 折叠屏与大屏 | 🟡 | 窗口宽度四档：600dp 起改为侧栏导航并限宽居中，840dp 起录音库与待办两列，1200dp 起概览与我的双栏、列表三列；现场录音在半开桌面姿态把控制面板放到铰链下方。规则见 [FOLDABLE.md](FOLDABLE.md)；真机上用 `wm size` / `wm density` 模拟验证，尚无折叠真机实测 |
| 手机横屏 | 🟡 | 横屏改为两栏：概览、录音库、待办、录音详情（原文常驻右栏）、转写过程、现场录音、首次向导各有横屏布局，页头压成一行、主要动作进左栏。规则见 [LANDSCAPE.md](LANDSCAPE.md)；以模拟手机尺寸验证，尚未在真机横屏实测 |
